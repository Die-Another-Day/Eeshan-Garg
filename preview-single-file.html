About

Defensive by focus, offensive by training.

My route into security wasn't a straight line from a textbook. It came from labs, CTFs and late-night PCAP files — pulling apart network traffic until a MitM attack or a quiet data exfiltration finally made sense. That hands-on habit is still how I learn, and it's why I publish my investigations instead of just finishing them.

I hold the CRTA (Certified Red Team Analyst) certification, which taught me how attackers actually move. I use that every day on the defensive side: triaging alerts, hunting through logs in Splunk, and asking "if I were the attacker, what would I do next?"

I'm based in Vadodara, Gujarat, pursuing a B.Tech in Computer Science & Engineering (2023–2027, CGPA 8.2) at Parul University — coursework in Network Security, Ethical Hacking, Digital Forensics and Cloud Security. Alongside my degree I've trained across 25+ global platforms, including IBM, Cisco, EC-Council and Homeland Security programmes.

What I'm looking for now is a SOC or security analyst seat where I can do this for a real organisation — monitor, investigate, respond, and keep getting better at it.

Published research

The paper — UASAF

SSRN · 2026 · Research Publication

Unified Application Security Assessment Framework (UASAF)

Garg, E. (2026)

I developed the Unified Application Security Assessment Framework, integrating static code analysis, B2R CTF exploit-chain simulation, and phishing vectors into one assessment model. The headline finding: 94.3% of exploitable attack chains involve compounding vulnerabilities — single flaws rarely break an application on their own; it's the chain that does it. That's exactly why I assess applications the way an attacker chains them.

Read the paper on SSRN ↗ DOI: 10.2139/ssrn.7014078

Python · FastAPI · CIS Benchmarks · NIST 800-53

Compliancity — Live Portal ↗

A full-stack, agent-based platform that scans Linux and Windows hosts against a 19-control security checklist mapped to CIS Benchmarks and NIST 800-53, then produces a severity-weighted compliance score — a disabled firewall counts far more than a missing screen-lock timeout. It tracks configuration drift between scans and exports reports as PDF, HTML or JSON. Try it live at the portal, or see the code on GitHub ↗.

GRC · Hardening · Automation · Live App

Debian 12 · Linux Kernel · XFCE · Python

SecureOS — A Real Bootable Cybersecurity OS ↗

A real, bootable Debian 12 Linux OS — not a web demo. It started in August 2025 as LoveOS, a web-based OS, and became SecureOS: real kernel 6.1.0-54, GRUB, systemd, and a localhost-only web console with real Nmap, real log analysis and real hashing, for your own lab only. Version 3 adds the basics every OS has — filesystem and file manager, drivers, persistent logging, task manager, battery and Wi-Fi/Ethernet via NetworkManager — and a GUI on demand: boot stays in the terminal, then secureos-gui starts an XFCE desktop, like WSL's kex.

Operating Systems · Linux · SOC Lab · GUI on Demand
